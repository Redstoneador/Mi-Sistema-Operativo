# RTOS Didáctico para STM32F103C8T6 (Blue Pill)

## Prerrequisitos de Software
1. Visual Studio Code con la extensión **PlatformIO IDE** instalada.
2. Toolchain de compilación para arquitecturas ARM (`toolchain-gccarmnoneeabi`).

## Estructura del Proyecto
- `include/`: Archivos de cabecera (`kernel.h`, `sync.h`, `uart.h`).
- `src/`: Código fuente del kernel (`kernel.c`, `sync.c`, `uart.c`, `main.c`).

## Instrucciones de Compilación y Carga

### 1. Clonar o abrir el proyecto
Abre la carpeta raíz del proyecto en PlatformIO IDE.

### 2. Compilar el código (Build)
Para verificar la integridad del código y compilar el firmware sin errores, ejecuta en la terminal de PlatformIO:
```bash
pio run
